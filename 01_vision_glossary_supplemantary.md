#Glossary

| Term | Explanation |
| Hero | Character controlled by player |
| Game Object | Anything placed on map; static objects, items, containers, enemies, characters |
| Static Object | Immovable objects blocking movements; wall, crates |
| Item | Small object can be taken on the ground; tube, weapon, power cell |
| Container | Object holding items, can be opened with OPEN, BREAK |
| Searchable | Object or location with SEARCH action that hero may find an item |
| Action | Interactions with objects; TAKE, DRINK, EQUIP ... |
| Effect | The result of an executed Action | 
| Inventory | 4x4 item storage of hero |
| HP, STR, SHIELD, ENERGY | 4 character stats |
| Alien, Android | Two types of enemy |
| Melee / Ranged Weapon | Weapon used on adjacent tiles / weapon firing bullets in a line |
| Adjacent tiles | 3x3 tile area where hero is in the center |
